# some

Проверить значения нескольких атомов или элементы одного атома-массива. Импорт из `jotai-holo` или `jotai-holo/vanilla`.

## Использование

```ts
import { some } from 'jotai-holo/vanilla';
some([$first, $second], (value) => value.available);
some({ first: $first, second: $second }, (value) => value.available);
some($items, (item) => item.available);
```

## Контракт

Возвращает нативный атом только для чтения. Объявление ничего не вычисляет. Вычисление и кеш принадлежат текущему Jotai store; одинаковый результат не уведомляет React. Ошибки распространяются по правилам Jotai. Эти операторы не ожидают async-атомы автоматически; используйте асинхронный derived atom.

Предикат получает (value, index); для объекта порядок совпадает с Object.values. Проверка останавливается на первом совпадении. Последующие атомы остаются непрочитанными. Атом-массив является одной зависимостью, отдельной подписки на его элементы нет. Пустой набор даёт false. Предикат синхронный и чистый.

## Почему такой API

Имя делает обычную проверку или расчёт понятными в месте объявления. Для произвольного преобразования полного снимка есть `ion`, для сложных динамических зависимостей — `atom(get => …)`. Дополнительного движка подписок или графа операторов нет.
