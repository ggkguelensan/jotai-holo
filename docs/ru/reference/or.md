# or

Проверить, что хотя бы один булев атом истинен. Импорт из `jotai-holo` или `jotai-holo/vanilla`.

## Использование

```ts
import { or } from 'jotai-holo/vanilla';
or([$isOwner, $isAdmin]);
or({ owner: $isOwner, admin: $isAdmin });
```

## Контракт

Возвращает нативный атом только для чтения. Объявление ничего не вычисляет. Вычисление и кеш принадлежат текущему Jotai store; одинаковый результат не уведомляет React. Ошибки распространяются по правилам Jotai. Эти операторы не ожидают async-атомы автоматически; используйте асинхронный derived atom.

На входе синхронные булевы атомы. Чтение останавливается на первом true. Пустой набор даёт false. При смене ветки ненужные зависимости отписываются.

## Почему такой API

Имя делает обычную проверку или расчёт понятными в месте объявления. Для произвольного преобразования полного снимка есть `ion`, для сложных динамических зависимостей — `atom(get => …)`. Дополнительного движка подписок или графа операторов нет.
