# Documentation changes

For changes to canonical documentation, displayed/runnable examples, or the
shared documentation renderer:

1. Follow [example conventions](design/example-conventions.md) and the
   [editorial rubric](design/docs-editorial-review.md).
2. Before completing the change, delegate an independent review using
   [.agents/reviewers/documentation-examples.md](.agents/reviewers/documentation-examples.md).
   Give the reviewer the changed paths, reader goal and current implementation.
3. Resolve blocking findings, then request a re-review. Report any remaining
   findings and checks not performed. A reviewer approval does not replace
   typechecking, documentation checks or relevant browser verification.

Keep these rules project-local. The reviewer prompt is the authoritative source
for its checklist; do not copy it into additional agent configuration files.
